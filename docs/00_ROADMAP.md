# Objetivo de la versión 1.0

Desarrollar una plataforma web que permita gestionar acciones de formación continua dirigidas al talento humano en salud, incluyendo la administración de usuarios, publicación de contenidos, evaluación del aprendizaje, generación de certificados e indicadores de cumplimiento para una o varias Instituciones Prestadoras de Servicios de Salud (IPS).
