# VISIÓN DEL PROYECTO

# HospitalLearning

Sistema de Gestión de Acciones de Formación Continua para el Talento Humano en Salud

---

# 1. ¿Qué es HospitalLearning?

HospitalLearning es una plataforma web diseñada para gestionar las acciones de formación continua del talento humano en salud, facilitando la administración de usuarios, la publicación de contenidos educativos, la evaluación del aprendizaje, la generación de certificados y el seguimiento de indicadores institucionales.

La plataforma busca convertirse en una herramienta de apoyo para los procesos de calidad, habilitación, seguridad del paciente y mejoramiento continuo de las Instituciones Prestadoras de Servicios de Salud (IPS).

---

# 2. Problema que resuelve

En muchas IPS las actividades de formación se gestionan mediante listas de asistencia, archivos de Excel, carpetas compartidas y documentos físicos, lo que dificulta:

- Organizar las acciones de formación.
- Conservar la evidencia documental.
- Verificar el cumplimiento de las capacitaciones.
- Consultar el historial de formación del personal.
- Generar reportes para auditorías y procesos de habilitación.

HospitalLearning centraliza toda esta información en una única plataforma.

---

# 3. Objetivo General

Desarrollar una plataforma web que permita planificar, administrar, ejecutar, evaluar y certificar las acciones de formación continua dirigidas al talento humano en salud.

---

# 4. Objetivos Específicos

- Administrar usuarios y roles.
- Publicar acciones de formación.
- Gestionar una biblioteca documental institucional.
- Facilitar el acceso a contenidos educativos virtuales.
- Aplicar evaluaciones en línea.
- Generar certificados automáticos.
- Mantener el historial de formación de cada usuario.
- Generar indicadores y reportes para apoyar la gestión institucional.

---

# 5. Alcance de la Versión 1.0

La primera versión permitirá:

- Gestión de usuarios.
- Inicio de sesión.
- Creación de acciones de formación.
- Biblioteca documental.
- Material multimedia.
- Evaluaciones.
- Certificados.
- Dashboard.
- Reportes.

La arquitectura quedará preparada para soportar múltiples IPS en versiones futuras.

---

# 6. Principios del Proyecto

HospitalLearning será desarrollado bajo los siguientes principios:

- Simplicidad para el usuario.
- Escalabilidad.
- Organización de la evidencia documental.
- Uso de terminología propia del sector salud colombiano.
- Modularidad.
- Seguridad de la información.
- Facilidad de mantenimiento.
